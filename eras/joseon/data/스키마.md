# 데이터 스키마 — 조선 시대팩 (`eras/joseon/data/`)

필드 이름은 **설계서 10-5**를 따른다. 데이터는 `.js` 파일이다(`index.html`을 더블클릭해 file://로 열어도 읽히게). 각 파일은 `window.JK.eraData`의 배열·객체에 값을 넣는다. 엔진 코드에는 시대 글을 넣지 않는다.

## 파일 나누기 (왕별 — 여러 세션이 왕마다 동시에 카드를 더할 수 있게)

```
data/common/roles.js     인물 인형(모자·옷·소품) — 손으로 쓴다
data/common/records.js   실각 기록·칭호·도감
data/common/daily.js     여러 왕에 나오는 일상 카드(D001~D137)
data/<왕>/cards.js       그 왕의 사관·역사·장치·사슬·희귀 카드와 그 왕 전용 일상 카드(DT101 …)
data/<왕>/quizzes.js     그 왕의 사관 퀴즈
```
왕 id: `taejo` · `sejong` · `seonjo` · `yeongjo` · `gojong`. 새 왕을 붙이면 `index.html`에 그 왕 폴더의 두 줄을 더한다.

**글은 `설계서.md`가 정본이다.** `common/daily.js`·`common/records.js`·`<왕>/*.js`는 `python tools/import-design.py <왕 id…>`로 만든다(직접 고치지 않는다). 설계서 표에 기계로 읽을 칸이 없는 화면 연출(세울 건물, 하늘 글씨 등)은 그 스크립트의 `STAGE_FX`에 카드 id별로 적는다.

**고치면 반드시**: `node tools/check-data.mjs` (오류 0) → 글자가 늘었으면 `python tools/subset-fonts.py tools/fonts-src` → `index.html`의 `?v=` 숫자 올리기.

## 카드 (10-5 cards.json)

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | ● | `T05`, `D001`, `DT101`, `C01a` … 겹치면 안 된다 |
| `kind` | ● | `sagwan`(사관 두루마리, 버튼 하나) · `history` · `device` · `daily` · `chain` · `rare` · `legend` |
| `stages` | ● | 나올 수 있는 왕 목록 |
| `order` | sagwan·history | 그 왕 안에서 나오는 순서 |
| `required_in` | | ★필수 왕 |
| `rarity` | daily·rare | `common` / `uncommon` / `rare` / `legend` |
| `conditions` | | 나오는 조건 — **조건 식**(`engine/cond.js`, 아래). 배열이면 모두 참일 때. 문법이 틀리면 검사 도구가 잡는다 |
| `conditions_text` | | 설계서의 한국어 조건 원문(사람이 읽는 메모, 엔진은 읽지 않음) |
| `grain` | 위기·사관 빼고 | **결(10-9)**: `balance` 저울 · `complex` 복합 · `gift` 선물 · `mire` 수렁 · `seed` 씨앗 · `gamble` 도박. 설계서에 `결:` 줄이 없으면 변환기가 10-9-2 셈 방법으로 붙인다 |
| `gamble` | 도박형 | `{ side: 'right'|'left', win: { effects, this_run }, lose: { effects, this_run } }` — 그 버튼은 미리보기가 '?'이고, 고르면 난이도표(`era.grain.gambleWin`) 확률로 갈린다. 역사 카드에는 쓰지 않는다 |
| `seed` | 씨앗형 | `{ fruit_id, after_n, side? }` — 고르면 `after_n`장 뒤에 열매 카드(`id` 끝 `f`)가 끼어든다. side가 있으면 그 버튼만 |
| `event` | 역사(분기) | 비교 화면의 사건 이름(`천도`) — 10-10-3 표 첫 칸 |
| `event_type` | 역사 | 진엔딩 셈(10-11-1): `normal` 보통 사건(좌우 = 실제대로, 다른 길 = 다름) · `judge` 열린 사건-판단(좌우 어느 쪽이든 실제대로) · `life` 열린 사건-생명(잠금 없음, 진엔딩 셈에서 뺌) |
| `paths` | 역사(분기) | **역사 분기(10-10)**: `{ real: { how_right, how_left, lock_right?, lock_left? }, alt: [다른 길] }`. 잠김은 `{ when: 조건 식, reason: '곳간이 비어 …' }`. **난이도별 실제 경로 요구(10-11-2)** `require{ sprout, normal, sage, annals: 조건 식 }` + `require_reason` — 못 채우면 좌우가 함께 잠기고(새싹은 "국고 8 더", 보통은 게이지 이름까지 덧붙임) 다른 길은 조건 없이 열린다. 앞 사건 플래그는 `real(T02)` |
| `year` | | 화면에 쓰는 연도 |
| `who` | ● | `{ name: '도읍 터를 살핀 신하', doll: 'official_red' }` — doll은 `common/roles.js` |
| `line` | ● | 대사, **2문장 이내** |
| `single` | sagwan | 버튼 하나의 글 (`'기록을 넘긴다'`) |
| `choice_type` | 선택 카드 | `how`(어떻게 할지 — 두 버튼 모두 그 일이 일어남) / `oppose`(반대가 있는 카드 — 결과 4단계, 대가가 큼) / `free`(일상) |
| `choices.right` / `choices.left` | 선택 카드 | `{ label, effects, device, this_run, build_state, build }` — label 4~10자 동사구, effects `{ people, nobles, treasury, army }`(보통 기준 값, 난이도 배율은 엔진이 곱함), **this_run 「이번 판에서」**, **build_state `smooth` 순조 / `forced` 억지 / `late` 늦게**(설계서 7-4, 그 카드의 첫 건물), build 세울 것(`map.js` buildings 키) |
| `against` | oppose | 역사를 거스르는 쪽(`right`/`left`). 고르면 "그래도 역사는 흘렀다" 연출. 변환기가 "~했지만 →"으로 시작하는 쪽을 찾아 넣는다 |
| `real_history` | 역사 카드 ● | **📜 「실제 역사」** — 두 버튼 공통. 「이번 판에서」와 함께 두루마리 카드로 뜬다 |
| `out_of_textbook` | ● | `[교과서 밖]` 띠 |
| `sources` | 역사 카드 ● | `{ type: 'guide', page: '233', tb: '75' }`(지도서·교과서 쪽) 또는 `{ type: 'web', title, url }` |
| `sources_text` | | 설계서 근거 칸 원문(사관 모드·도감용) |
| `general` | daily | 특정 역사 사실을 주장하지 않는 생활 장면 |
| `learn` | | 배움 포인트 |
| `fx` | | 연출: `{ build, note, flag, boats, skyText: '조선', glyphs: { heungin: '仁' } }` |
| `caution` | | 수위·표현 주의 |

**다른 길** `paths.alt[]`: `{ id, label, unlock(조건 식), lock_reason, effects, this_run, set_flag('F_개경'), build[](이번 왕 동안 서는 이름 없는 장식), skip[](빠지는 뒤 카드), variants{원래 id: 변형판 id}, crisis_mult{'army:low': 1.5}, merge_text, merge_real{ text, sources } }`.
화면에는 열린 것 가운데 먼저 적힌 하나만 보인다. 한 왕에서 다른 길은 최대 3개(`era.branch`). 세 버튼이 모두 잠기면 실제 경로의 가벼운 쪽을 연다. 고르면 「실제 역사」 두루마리 대신 "실제 역사와 달라졌어요 📜"가 붙고, 실제 경로라면 섰을 건물은 다음 왕 시작 때 서 있다(합류). 열림·잠김 조건(한국어)을 조건 식으로 옮긴 것과 섬 모습은 `tools/import-design.py`의 `ALT_FX`, 글(버튼·이유·플래그·합류 문장)은 설계서 10-10-3 표에서 읽는다.

**조건 식** (`engine/cond.js`, 카드 `conditions`·버튼 잠김·다른 길 열림이 모두 같은 문법):
`gauge(people) < 30` · `chosen(T07,R)` · `seen(SX2)` · `seen_ever(SX2)` · `flag(F_개경)` · `device(S) >= 5` · `run_count >= 10` · `stage(taejo)` · `diff(sprout)` · `&&` `||` `!` `( )`. eval을 쓰지 않는다.

## 위기 카드 (설계서 10-8, v3)

`kind: 'crisis'` + `gauge`(people/nobles/treasury/army) · `side`(low/high) · `level`(`warn` 예고 / `event` 위기 사건 / `followup` 후속) · `name`(위기 이름, 사건·후속) · `step`(후속 단계, 2) · `strong`(강한 대응 쪽, `right`) · `game_event: true`(`[게임 속 일]` 띠) · `damage{ targets: [건물 키] }`(없으면 지어진 이름 있는 건물 하나) · `similar{ text, sources, out_of_textbook }`(「비슷한 실제 일」, 작게) + 나머지는 일반 카드와 같다. 설계서 10-5의 `crisis_warn` / `crisis` / `crisis_follow`는 여기서 `kind: 'crisis'` + `level` 하나로 쓴다. 변환기가 설계서 10-8-5 표에서 만든다(`NT`·`KT`·`KTb`).

- **게이지가 0·100이어도 바로 실각하지 않는다.** 엔진(`engine/crisis.js`)이 카드를 넘길 때마다 ① 기한이 된 후속 → ② 예고(안정→경고로 처음 들어감) → ③ 위기 사건(가장 끝에 가까운 게이지 하나, 구간 확률 × 난이도 × 다른 길 배율) 차례로 다음 자리에 끼운다. 사건 뒤 `rest`장은 쉰다(끝 구간은 1장).
- 위기 사건·후속 카드는 고른 순간 **실각 확률 = 구간 기본값 × 대응 배율(강/가벼움, 대응 게이지가 이미 위험이면 약해짐) × 난이도 (+ 후속 가산)**으로 굴려 실각 또는 수습("버팀" 도장). 수습하면 문제 게이지는 최소 거리 8까지 올라오고, 그 위기 종류는 `cooldown[게이지:방향][난이도]`장(후속을 수습했으면 +2) 동안 다시 안 터진다(아이콘 옆 ⏳남은 장수). 쉬는 장수가 끝났을 때 아직 거리 15 이하이면 바로 다음 카드에 후속 위기(먹구름), 16 이상으로 고쳐 두었으면 후속 없음. 위험 이하에서 수습하면 건물 하나가 손상(다음 왕에서 고쳐짐).
- 숫자는 모두 `era.js`의 `crisis`(10-8 표), 장면 자리는 `map.js`의 `crisis`. 상태(쿨다운·후속·예고 수·손상·기록)는 판 저장에 들어간다.

## 사관 퀴즈 (10-5 quiz.json)

`about: [카드 id]` — 이어진 역사 사건(변환기가 근거 칸의 카드 id나 같은 지도서 쪽으로 찾음). 다른 길로 간 사건과 이어진 문항은 뽑힐 확률 ×2, 틀리면 비교 화면의 그 줄을 다시 보여 준다(10-10-5).

`{ id, stage, question, answer, wrong: [오답 2개(4지선다용이면 3개)], sources, sources_text, out_of_textbook, checked_against_review_site }` — 보기 순서는 게임이 섞는다. 왕이 바뀔 때 3문항(교과서 밖은 많아야 1개). 보기 수는 난이도를 따르되 오답이 모자라면 3개.

## 인물 `common/roles.js`

`id: { name, tag, cloth, trim, hat, items: [...], bg }` — hat·items는 `eras/joseon/models.js`의 `HATS`·`ITEMS`. 신분은 모자·옷·소품으로만 구분한다(얼굴·몸은 모두 같다).

## 실각·칭호·도감 `common/records.js`

- 실각: `{ id, gauge, at: 0|100, side, name, text }` — v3에서는 "그 게이지·쪽의 위기에서 무너졌을 때"(id는 예전 저장과 같게 `people0` 등)
- 칭호: `{ id, name, hint, cond, rule }` — rule은 엔진이 판정하는 규칙: `edgeClear` · `held5` · `heldAtEnd` · `cancel3`(위기, 10-8-7) · `allReal` · `alt5` · `flag:F_…` · `explorer`(다른 길, 10-10-6). 아직 없는 것은 `later`
- 도감: `{ id, cat, name, band, opens: [카드 id], desc, outside }`. 건물 칸에는 그 건물이 선 모습(억지로·늦게 지은 ○○, 세 모습 ★)이 붙는다

## 난이도 (`era.js`의 `difficulty`, 설계서 10-7)

`sprout`(새싹) · `normal`(보통, 기본) · `sage`(성군) · `annals`(실록 도전). 단계마다 `mult`(게이지 배율) · `safe`(안전 구간) · `warn`(위험 경고) · `preview`(미리보기: arrows/dots/flat/none) · `carry`(다음 왕이 이어받는 몫) · `quizOptions` · `quizRetry` · `quizBonus` · `afterFall`(reset50/same/run) · `hint`(사관의 귀띔) · `stage`(왕별 장치 숫자, P1~P4) · `unlock`. **역사·카드 순서·「실제 역사」는 난이도와 무관하다.**

## 건물 (`eras/joseon/map.js`의 `buildings`)

`kind: 'single'`(한 채, `at: { site } | { gate } | { riverPhi }`) · `'spots'`(여러 자리) · `'village'`(마을) · `'wall'`(도성). `name`이 있으면 이름표가 뜨므로 **근거가 있어야 한다**(CREDITS.md).
