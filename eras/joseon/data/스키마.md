# 데이터 스키마 — 조선 시대팩 (`eras/joseon/data/`)

필드 이름은 **설계서 10-5**를 따른다. 데이터는 `.js` 파일이다(`index.html`을 더블클릭해 file://로 열어도 읽히게). 각 파일은 `window.JK.eraData`의 배열·객체에 값을 넣는다. 엔진 코드에는 시대 글을 넣지 않는다.

## 파일 나누기 (왕별 — 여러 세션이 왕마다 동시에 카드를 더할 수 있게)

```
data/common/roles.js     인물 인형(모자·옷·소품) — 손으로 쓴다
data/common/records.js   실각 기록·칭호·도감
data/common/daily.js     여러 왕에 나오는 일상 카드(D001~D137)
data/<왕>/cards.js       그 왕의 사관·역사·장치·사슬·희귀 카드와 그 왕 전용 일상 카드(DT101 …)
data/<왕>/quizzes.js     그 왕의 사관 퀴즈
```
왕 id: `taejo` · `sejong` · `seonjo` · `yeongjo` · `gojong`. 새 왕을 붙이면 `index.html`에 그 왕 폴더의 두 줄을 더한다.

**글은 `설계서.md`가 정본이다.** `common/daily.js`·`common/records.js`·`<왕>/*.js`는 `python tools/import-design.py <왕 id…>`로 만든다(직접 고치지 않는다). 설계서 표에 기계로 읽을 칸이 없는 화면 연출(세울 건물, 하늘 글씨 등)은 그 스크립트의 `STAGE_FX`에 카드 id별로 적는다.

**고치면 반드시**: `node tools/check-data.mjs` (오류 0) → 글자가 늘었으면 `python tools/subset-fonts.py tools/fonts-src` → `index.html`의 `?v=` 숫자 올리기.

## 카드 (10-5 cards.json)

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | ● | `T05`, `D001`, `DT101`, `C01a` … 겹치면 안 된다 |
| `kind` | ● | `sagwan`(사관 두루마리, 버튼 하나) · `history` · `device` · `daily` · `chain` · `rare` · `legend` |
| `stages` | ● | 나올 수 있는 왕 목록 |
| `order` | sagwan·history | 그 왕 안에서 나오는 순서 |
| `required_in` | | ★필수 왕 |
| `rarity` | daily·rare | `common` / `uncommon` / `rare` / `legend` |
| `conditions` | | 나오는 조건(설계서 원문). 조건 식 해석은 P5 |
| `year` | | 화면에 쓰는 연도 |
| `who` | ● | `{ name: '도읍 터를 살핀 신하', doll: 'official_red' }` — doll은 `common/roles.js` |
| `line` | ● | 대사, **2문장 이내** |
| `single` | sagwan | 버튼 하나의 글 (`'기록을 넘긴다'`) |
| `choice_type` | 선택 카드 | `how`(어떻게 할지 — 두 버튼 모두 그 일이 일어남) / `oppose`(반대가 있는 카드 — 결과 4단계, 대가가 큼) / `free`(일상) |
| `choices.right` / `choices.left` | 선택 카드 | `{ label, effects, device, this_run, build_state, build }` — label 4~10자 동사구, effects `{ people, nobles, treasury, army }`(보통 기준 값, 난이도 배율은 엔진이 곱함), **this_run 「이번 판에서」**, **build_state `smooth` 순조 / `forced` 억지 / `late` 늦게**(설계서 7-4, 그 카드의 첫 건물), build 세울 것(`map.js` buildings 키) |
| `against` | oppose | 역사를 거스르는 쪽(`right`/`left`). 고르면 "그래도 역사는 흘렀다" 연출. 변환기가 "~했지만 →"으로 시작하는 쪽을 찾아 넣는다 |
| `real_history` | 역사 카드 ● | **📜 「실제 역사」** — 두 버튼 공통. 「이번 판에서」와 함께 두루마리 카드로 뜬다 |
| `out_of_textbook` | ● | `[교과서 밖]` 띠 |
| `sources` | 역사 카드 ● | `{ type: 'guide', page: '233', tb: '75' }`(지도서·교과서 쪽) 또는 `{ type: 'web', title, url }` |
| `sources_text` | | 설계서 근거 칸 원문(사관 모드·도감용) |
| `general` | daily | 특정 역사 사실을 주장하지 않는 생활 장면 |
| `learn` | | 배움 포인트 |
| `fx` | | 연출: `{ build, note, flag, boats, skyText: '조선', glyphs: { heungin: '仁' } }` |
| `caution` | | 수위·표현 주의 |

## 위기 카드 (설계서 10-8 — 자리만 있음, 카드는 10-8이 나오면 넣는다)

`kind: 'crisis'` + `gauge`(people/nobles/treasury/army) · `side`(low/high) · `level`(`warn` 예고 / `event` 사건) · `damage`(사건 때 손상될 건물: `{ target: 'random' | 건물 키 }`) + 나머지는 일반 카드와 같다(`who`, `line`, `choices` …). 왕별 `cards.js`에 넣는다.

- 엔진(`engine/crisis.js`)이 카드를 넘길 때마다 게이지 구간을 보고, 구간에 있으면 `era.crisis.chance[구간] × 난이도 crisisMult` 확률로 그 게이지·쪽에 맞는 카드를 **다음 자리에 끼워 넣는다**(경고 구간 → 예고, 위험 구간 → 사건). 한 판에 같은 위기 카드는 한 번, 끼운 뒤 `rest`장은 쉰다. 역사 카드 순서는 그대로 한 칸씩 밀린다.
- 사건 카드를 넘기면 붉은 경보·어두워짐·북과 함께, 이미 세운 이름 있는 건물 하나가 "손상"(연기 기둥·돌무더기, 모양은 그대로) 모습이 된다. 이번 판에서만이고 저장된다.
- 구간 숫자·알림 글·세계 반응(사람 무리·깃발·연기·봉수 불·불빛)은 `era.js`의 `crisis`, 자리는 `map.js`의 `crisis`. 지금 숫자는 임시다.

## 사관 퀴즈 (10-5 quiz.json)

`{ id, stage, question, answer, wrong: [오답 2개(4지선다용이면 3개)], sources, sources_text, out_of_textbook, checked_against_review_site }` — 보기 순서는 게임이 섞는다. 왕이 바뀔 때 3문항(교과서 밖은 많아야 1개). 보기 수는 난이도를 따르되 오답이 모자라면 3개.

## 인물 `common/roles.js`

`id: { name, tag, cloth, trim, hat, items: [...], bg }` — hat·items는 `eras/joseon/models.js`의 `HATS`·`ITEMS`. 신분은 모자·옷·소품으로만 구분한다(얼굴·몸은 모두 같다).

## 실각·칭호·도감 `common/records.js`

- 실각: `{ id, gauge, at: 0|100, name, text }`
- 칭호: `{ id, name, hint, cond, rule }` — rule은 엔진이 판정하는 규칙(`edgeClear` …, 아직 없는 것은 `later`)
- 도감: `{ id, cat, name, band, opens: [카드 id], desc, outside }`. 건물 칸에는 그 건물이 선 모습(억지로·늦게 지은 ○○, 세 모습 ★)이 붙는다

## 난이도 (`era.js`의 `difficulty`, 설계서 10-7)

`sprout`(새싹) · `normal`(보통, 기본) · `sage`(성군) · `annals`(실록 도전). 단계마다 `mult`(게이지 배율) · `safe`(안전 구간) · `warn`(위험 경고) · `preview`(미리보기: arrows/dots/flat/none) · `carry`(다음 왕이 이어받는 몫) · `quizOptions` · `quizRetry` · `quizBonus` · `afterFall`(reset50/same/run) · `hint`(사관의 귀띔) · `stage`(왕별 장치 숫자, P1~P4) · `unlock`. **역사·카드 순서·「실제 역사」는 난이도와 무관하다.**

## 건물 (`eras/joseon/map.js`의 `buildings`)

`kind: 'single'`(한 채, `at: { site } | { gate } | { riverPhi }`) · `'spots'`(여러 자리) · `'village'`(마을) · `'wall'`(도성). `name`이 있으면 이름표가 뜨므로 **근거가 있어야 한다**(CREDITS.md).
