# 데이터 스키마 — 조선 시대팩 (`eras/joseon/data/*.js`)

데이터는 `.js` 파일이다(`index.html`을 더블클릭해 file://로 열어도 읽히게). 각 파일은 `window.JK.eraData`의 배열·객체에 값을 넣는다. 엔진 코드에는 시대 글을 넣지 않는다.

**고치면 반드시**: `node tools/check-data.mjs` (오류 0이어야 한다) → 글자가 늘었으면 `python tools/subset-fonts.py tools/fonts-src` → `index.html`의 `?v=` 숫자 올리기.

## 카드 `cards.js`

| 칸 | 필수 | 뜻 |
|---|---|---|
| `id` | ● | `T05`, `D001`처럼 설계서 ID 그대로. 겹치면 안 된다 |
| `type` | ● | `scroll`(사관 두루마리, 버튼 하나) · `history`(역사 사건, 순서 고정) · `daily`(일상) · `device`(장치, P1부터) |
| `stage` | scroll·history | 왕 id (`era.js`의 `stages[].id`) |
| `order` | scroll·history | 그 왕 안에서 나오는 순서(작은 수가 먼저) |
| `daily` | daily | `{ kings: ['taejo','sejong'], required: 'taejo' }` — 나올 수 있는 왕들, ★필수인 왕 |
| `who` | ● | 인물 인형 id (`roles.js`) |
| `whoName` | | 카드에 뜨는 이름을 인형 이름과 다르게 할 때 (예: `'도읍 터를 살핀 신하'`) |
| `year` | | `'1394'`, `'1392 봄'` |
| `outside` | | `true`면 `[교과서 밖]` 띠. 출처 필수 |
| `text` | ● | 대사. **2문장 이내** |
| `single` | scroll | 버튼 하나의 글 (예: `'기록을 넘긴다'`) |
| `right` / `left` | history·daily | `{ label, fx, result }` — label: 무엇을 고르는지 분명한 **동사구**(예: `'조약을 맺는다'`), fx: `{ people, nobles, treasury, army }` 변화(±5·10·15, 큰 사건만 20), result: 고른 뒤 뜨는 짧은 반응 |
| `record` | | 📜 사관 기록(실제 역사, 어느 쪽을 골라도 같다). 결과 뒤에 두루마리 카드로 뜬다 |
| `build` | | 세워지는 것(`map.js`의 `buildings` 키). **오른쪽이면 그 자리에서, 왼쪽이면 사관 기록 뒤에(조금 늦게) 결국 선다** |
| `source` | history·scroll ● | 근거 목록. `{ book: '지도서', page: '233', tb: '75' }` 또는 `{ site: '조선왕조실록', url: 'https://…' }` |
| `learn` | | 배움 포인트 |
| `direction` | | 설계서 연출 한 줄(참고용) |
| `note` | | 주의(참고용) |
| `temp` | | `true`면 임시 글(검사에서 경고) |

## 사관 퀴즈 `quizzes.js`

`{ id, stage, q, answer, wrong: [오답 2개], source: [...], outside }` — 3지선다, 보기 순서는 게임이 섞는다. 왕이 바뀔 때 그 왕 문항 가운데 3개(교과서 밖은 많아야 1개).

## 인물 `roles.js`

`id: { name, tag, cloth, trim, hat, items: [...], bg }` — hat·items는 `eras/joseon/models.js`의 `HATS`·`ITEMS` 키. 신분은 모자·옷·소품으로만 구분한다(얼굴·몸은 모두 같다).

## 실각·칭호·도감 `records.js`

- 실각: `{ id, gauge, at: 0|100, name, text }`
- 칭호: `{ id, name, hint, rule }` — rule은 엔진이 아는 규칙 이름(`engine/game.js`: `edgeClear`, `noFallStage`, `quizPerfect` … 단계마다 늘어난다)
- 도감: `{ id, cat: '인물'|'건물'|'물건'…, name, opens: [카드 id], desc, outside }` — 카드를 한 번 만나면 열린다

## 건물 (`eras/joseon/map.js`의 `buildings`)

`kind: 'single'`(한 채, `at: { site } | { gate } | { x, z }`) · `'village'`(마을, 인스턴싱) · `'wall'`(도성). `name`이 있으면 이름표가 뜨므로 **근거가 있어야 한다**(CREDITS.md 「화면 속 이름의 근거」에 적는다).
